    학습 경로¶

    단계 주제 노트 실습
    1 기초 파이썬 데이터, 수학, 머신러닝 6개 3개
    2 딥러닝 역전파, PyTorch, CNN, RNN 4개 1개
    3 LLM 토큰, 트랜스포머, 학습·추론, 프롬프트 4개 2개
    4 응용 RAG, LoRA, 에이전트, MCP 4개 4개

    시작하기¶

    1. 로드맵에서 현재 위치를 확인합니다.
    2. 1단계 첫 노트: NumPy부터 읽으며 코드를 직접 실행합니다.
    3. 연습문제를 풀고, 단계 끝의 실습을 합니다.
    4. 배운 것은 templates/note.md로 내 말로 정리해서 노트를 추가합니다.
